# Topological Protection of Photosynthetic Quantum Heat Engines

This repository contains the MATLAB code and numerical data associated with the research article **"Topological Protection of Photosynthetic Quantum Heat Engines"**.

The repository provides the computational materials supporting Figs. 2–4 of the main text and Supplementary Figs. 1–6.

## Repository Structure

### Code

The [`Code/`](./Code) directory contains MATLAB scripts for numerical calculations and figure generation. Additional computational files are organized in figure-specific subdirectories.

Detailed descriptions and instructions are provided in [`Code/README.txt`](./Code/README.txt).

### Data

The [`Data/`](./Data) directory contains the numerical data underlying Figs. 2–4 and Supplementary Figs. 1–6.

The data are provided in two formats:

* **Source_Data.xlsx:** Source data organized in spreadsheet format for inspection and reuse.
* **MATLAB .mat files:** Numerical arrays used to generate the corresponding figures.

Additional information is available in [`Data/README.txt`](./Data/README.txt).

## Reproducing the Figures

The figures can be reproduced using MATLAB and the numerical data provided in this repository.

After downloading the repository, add the `Code/` and `Data/` directories, including their subdirectories, to the MATLAB search path. Run the corresponding MATLAB plotting scripts to reproduce the figures.

Some scripts use precomputed numerical data, while the associated calculation scripts are provided for examining the underlying numerical procedures.

For further details, refer to the README files in the respective directories.
